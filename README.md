# Naila Kanaya Putri Dilan — Portfolio Website

A responsive portfolio website built with plain HTML, CSS, and JavaScript, based on the content and visual direction of the Canva PDF portfolio.

## Files
- `index.html` — page structure and portfolio content
- `style.css` — responsive layout, dark navy/purple/cyan styling, cards, and animations
- `script.js` — mobile navigation, experience filters, scroll reveals, and current year
- `assets/` — compressed page visuals rendered from the provided portfolio PDF

## Run locally in VS Code
1. Extract this project folder if you downloaded the ZIP.
2. Open the `naila-portfolio` folder in VS Code (`File` → `Open Folder`).
3. Open `index.html` in a browser, or use the Live Server extension and click **Go Live**.

## Publish with GitHub Pages
1. Create or open your GitHub repository.
2. Upload the contents of this folder (not the ZIP itself) to the repository root. Make sure `index.html`, `style.css`, `script.js`, and `assets/` are at the top level.
3. In the repository, open **Settings** → **Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/(root)`, then save.
5. Wait a few minutes and open the Pages URL shown on that settings page.

## Before publishing
- Review all text, dates, metrics, and contact details.
- Replace the rendered portfolio-page images in `assets/` with original photos or project images if you have them; the current images are page previews from the PDF.
- The site currently uses Google Fonts from a CDN; the rest of the site is static and needs no build tools.
